# VerdiWM Anonymous Project Page

A static anonymous project page for VerdiWM: Verifiable Differential Repair for World Models.

The page is intentionally authored and published without personal names, emails, or author identifiers.

## Page template

Layout, typography, navigation, cards, and hero canvas are adapted from
[ConfAL-WM/ConfAL-WM.github.io](https://github.com/ConfAL-WM/ConfAL-WM.github.io),
revision `30d8d4193bb4a06bd7e3e3a42df23bb1f07cd960`.
The upstream CSS is retained verbatim in `assets/confal-template.css`;
`assets/site.css` contains the light-blue palette and VerdiWM media integration.
The upstream repository did not include a standalone LICENSE file at that revision.
All research content, metrics, figures, and videos shown here belong to VerdiWM.

The page includes all 12 original research images, 16 replay videos, and 7 memory
nodes. Video dimensions are taken from the MP4 track headers to preserve each
native aspect ratio. Wide mosaics occupy a full row; robot pairs and Ctrl-World
replays use two columns on desktop and one on mobile.
